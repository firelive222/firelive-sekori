# Taller Integrador: Desarrollo Web y APIs 🚀

Aplicación web desarrollada para el **Técnico en Programación de Software (SENA)**. Consolida la integración de interfaces, lógica del cliente, servidor y consumo de servicios web bajo un flujo de trabajo profesional con Git y GitHub.

## 🎯 Objetivo y API Utilizada
Demostrar capacidades técnicas conectando capas de software con control de versiones. 
* **API:** Consumo de datos externos y renderizado asíncrono en formato JSON.

## 💻 Tecnologías
`HTML5` · `CSS3` · `JavaScript (ES6)` · `PHP` · `API REST` · `Git` · `GitHub`

## ⚙️ Funcionalidades Implementadas
* **Consultar y Mostrar:** Extracción de datos de API externa y renderizado dinámico.
* **Filtro de Resultados:** Sistema de búsqueda y filtrado de datos (Rama `feature/filtro`).
* **Manejo de Errores:** Validación y mensajes controlados ante fallos (Rama `fix/manejo-errores`).

## 🔄 Flujo de la Aplicación
```text
Usuario ➔ Formulario HTML ➔ JavaScript (fetch) ➔ API REST ➔ JSON ➔ Renderizado DOM
```

## 🚀 Ejecución Local
1. **Clonar:** `git clone https://github.com`
2. **Servidor:** Mover carpeta a `htdocs` (XAMPP) o `www` (Laragon).
3. **Iniciar:** Prender **Apache** desde el panel del servidor.
4. **Abrir:** Ir a `http://localhost/nombre-de-tu-carpeta/` en el navegador.

## ⚠️ Limitaciones y Aprendizajes
* **Limitación:** Dependencia de la disponibilidad y cuotas de la API externa seleccionada.
* **Aprendizaje:** Dominio de flujos de trabajo con ramas (`feature/`), Pull Requests y cierre de *Issues*.
